# 0.1.70 本地源码快照更新

观察日期：2026-10-26。对照基线：`ea5f00b6e0b621f539466eafa51952ce2caaed60`。

## 这次实际同步了什么

当前本地暂存运行时为 `0.1.70-release`。包数量仍为 29，没有新增或删除 skill 包。本次逐字节同步 30 个已有文件，新增一份第三方许可说明；81 个导出文件的完整校验值见 [SNAPSHOT.json](../../SNAPSHOT.json)。

30 个更新文件包括 15 份 `SKILL.md`、配套参考文档/脚本，以及两份 `requirements.lock`。早期仅扫描特定文本扩展名时得到 28 个更新文件；这里改为核对所有导出文件，补计了两份依赖锁文件。[完整路径清单](0.1.70-files.json)记录本次实际范围。

主要可见变化：

- **模型工具与环境**：多个模型 skill 增加或更新上游代码版本固定、环境说明和调用示例。`borzoi`、`evo2`、`fair-esm2`、`ligandmpnn`、`proteinmpnn`、`solublempnn`、`scgpt`、`scvi-tools` 均有说明变化。
- **SSH 计算**：更新 `CommandResult`、输入/输出路径、任务状态与结果收集方式；说明环境激活应写入命令，以及未结束任务的结果读取行为。
- **Modal 与托管推理**：同步 provider 脚本、环境文档及依赖锁文件；包括网络桥接和 token 信息查询相关的源码变化。本次没有执行这些 provider。
- **自定义 skill**：更新组织设置、写入审批、草稿/共享行为及格式/大小限制。它们描述的是源平台行为，不是本仓库或其他 agent 的执行规则。
- **随附工具**：文献检索、PDF、组图及叙事辅助脚本有修正；skill 打包工具增加对链接等文件的处理。
- **许可记录**：保留新增的 `THIRD_PARTY_LICENSES.md`，不对整个导出重新授权。

## 来源与可复核范围

文件来自本机已暂存的运行时，而非仍停留在旧内容的顶层 `skills` 目录。导出前逐文件与源树比对；本仓库校验脚本随后按清单检查完整性。原仓库的 29 份 `.catalog_stamp` 没有改动，作为历史标记单独列出，不用它们证明当前版本。

官方 macOS 下载包的 `Info.plist` 版本也为 0.1.70；只读检查后卸载挂载，未启动或安装应用。下载地址及 SHA-256 写入快照。版本相同不代表已经证明下载包内所有运行时字节与本地暂存树完全一致。
