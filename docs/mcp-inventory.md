# 随附 MCP 服务目录说明

[bundled-mcp.json](../catalogs/bundled-mcp.json)来自本地 0.1.70 运行时的静态目录检查：枚举 `bio-tools/lib/mcp_*/server.py`，记录包名、相对入口路径与入口文件 SHA-256，不导入或执行服务。

这 24 组入口包括文献、基因与本体、结构与相互作用、临床试验、化学、调控及组学档案等分组。一个分组可以封装多个工具或数据来源；目录中出现入口，不代表当前账号有权使用或已连接成功。

## 用到其他 agent 环境时

先确认所需 skill 涉及哪一类宿主能力，再使用目标环境已有的公开 MCP 服务或自行实现适配器。需要逐项明确工具输入/输出 schema、认证方式、查询来源、错误和重试行为，以及用户数据允许流向哪里。MCP 协议本身是开放规范，不能仅凭该协议或服务名称恢复后端实现。

本目录没有连接地址、认证状态或账户标识，不是可直接加载的 MCP 配置文件。CI 只验证目录结构和哈希格式；它无法独立验证未导出的服务实现，也不检验数据库连通性。服务入口哈希仅供日后与持有相同合法来源的本地文件比对。
