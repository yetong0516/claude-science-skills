# Claude Science Skills

A local export of the Claude Science skill definitions available in this workspace.

## Contents

The `skills/` directory contains 29 skill packages, including scientific literature review, figure composition, remote compute setup, protein structure and design tools, single-cell analysis, and skill authoring utilities.

This repository contains the skill files and their bundled references/scripts only. It does not include Claude Science runtime data, organization artifacts, conda environments, databases, authentication state, or credentials.

## Provenance

Exported from the local Claude Science installation under `~/.claude-science/skills`.
